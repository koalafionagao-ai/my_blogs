# Key Updates | 26-04-30

## 1 新模型

> [!NOTE]
> 4月堪称百模大战，大厂模型开始向Agent靠拢，努力成为“工作流基础设施”和“原生智能体引擎”；垂直领域和多模态也出现各显神功的小黑马：
>
>1. **大厂旗舰模型**：正在向智能体推理和超大上下文演进
> - **GPT-5.5 (OpenAI):** 在智能体推理、工具使用和效率方面实现了全面改进，进一步提升了编码和知识任务的性能
>     
> - **Kimi K2.6 (Moonshot AI):** 其 Thinking 变体专攻复杂推理，同时推出了用于文档/网络任务的 Agent 版本，以及用于大规模处理的 Agent Swarm 阵容
>     
> - **DeepSeek V4 Pro:** 拥有 1.6T 总参数，支持 100 万 token 的超大上下文窗口，以媲美全球顶级闭源模型的性能切入高端推理市场
>     
> - **Qwen3.6-Max-Preview (阿里云):** 增强了世界知识与指令遵循能力，在智能体编程方面取得了显著改进
>     
> - **Muse Spark (Meta):** 标志着 Meta 将核心策略从纯开源转向付费访问，意在通过底层 AI 实力巩固其广告业务护城河
>     
>2. **大厂低价底座：**主攻高并发与极致性价比
>
> - **DeepSeek V4 Flash:** 在保持 1M 上下文长度的同时，将输入输出价格压低至全行业极低水平（输出仅为 $0.28/百万 token），确立了性价比时代的门槛
>     
> - **Granite 4.1 LLMs (IBM):** 采用纯解码器密集架构，提供 3B、8B 和 30B 规模；其中 8B 模型通过强化学习，在工具使用上达到了上代 32B 模型的水平，极具成本效益
>     
> - **Kimi K2.6 Instant (Moonshot AI):** 专门为快速回复场景设计的极速响应变体
>     
>
>3. **专精模型**：垂直场景特定工作流中实现深度定制   
>
> - **MiMo-V2.5-Pro (小米):** 这是一个 1.02 万亿参数的开源混合专家模型，在软件工程和长周期一致性方面展现出显著优势
>     
> - **Mistral Medium 3.5:** 一款 1280 亿参数的密集模型，专为驱动 Vibe 远程智能体而生，能在云端稳定执行长时间的异步编码任务
>     
> - **Laguna XS.2 和 M.1 (Poolside):** 专为长期编码工作构建的智能模型，其中小尺寸的 XS.2 以极其出色的规模表现并开源，为开发者工具提供了优质底层
>     
> - **talkie:** 一款 130 亿参数的“复古”语言模型，其训练数据严格截止至 1930 年代，主要用于学术层面验证 AI 对科学发现的复现能力
>     
>
>4. **原生多模态**：多语言、跨模态、世界模型
  >  
>
> - **Nemotron 3 Nano Omni (NVIDIA):** 采用混合 Mamba-Transformer 架构，集成了专用编码器，极大地提升了长上下文中文档、音频和自动语音识别的处理效率
>     
> - **NEMOTRON OCRV2 (NVIDIA):** 利用合成数据管道，实现了极高的处理速度（单卡 34.7页/秒），并将非英语语言的 OCR 识别错误率降至接近零
>     
> - **ChatGPT Images 2.0 (OpenAI):** 改进了多图像推理和非拉丁文本（如日、韩、印地语）的渲染能力，并划分为即时和思考两种变体
>     
> - **Sapiens2 (Meta):** 以人为中心的高分辨率视觉模型，在十亿张人类图像上训练，在姿态估计和表面预测等实际应用中表现优异
>     
> - **多模态 3D 世界模型 (腾讯):** 创新的多模态框架，能够直接从文本、图像和视频中生成并重建 3D 世界
>     
> - **Vision Banana 通用模型:** 提出了一种跨任务的新范式，将视觉感知任务重新框架为图像生成来解决，展现了卓越的性能
>

## 2 新技术

> [!NOTE]
> 1. **端云协同混合推理**：平衡隐私、延迟与成本的最优解
  >  
>
> - Android 推出 Firebase AI Logic 实验性功能，允许在本地设备（Gemini Nano）和云端模型之间动态切换，试图建立“智能路由”——轻量级感知在端侧完成，复杂推理再上云
>     
> - 对于 C 端交互界面（尤其是在汽车零售座舱体验、或跨国旅行等对网络环境和隐私要求极高的场景中），未来的标准架构一定是“本地微型模型 + 云端大脑”的动态协同
>     
>
>2. **计费逻辑改变**：底层算力解耦、极大降低成本
  >  
>
> - “预填充即服务 (PrfaaS)” 实现了跨数据中心的 KVCache 传输；AutoSP 自动转换长上下文并行代码
>     
> - 现在的解法是将大模型的“读题理解（预填充阶段）”和“做题输出（解码生成阶段）”的算力彻底拆分
>     
> - 基于解耦逻辑，未来的 API 计费逻辑可能会发生根本性改变（例如为缓存预填充单独定价）
>     
>
>3. **Agent记忆持久化**
  >  
>
> - 开源工具 Stash 为 Agent 提供了跨会话的持久记忆能力；Perplexity 针对搜索模型进行信息收集和结构化评估的后训练；ElevenLabs 推出 Agent 模板
>     
> - 现在的技术正在为 Agent 搭建类似于人类大脑海马体的“长效工作记忆系统”
>     
>
>4. **突破传统 Transformer 天花板**：追求更深度的逻辑推演
  >  
>
> - 循环 Transformer 引入层间内部存储器；LaDiR 利用潜在扩散模型来增强大语言模型的文本推理能力
>     
> - 新技术正在探索新的数学机制（如扩散模型的迭代优化），让模型能够在不增加体量的前提下，进行长链条的复杂迭代推理
>     
> - 业务层未来可以原生支持类似人类的“慢思考”机制
>     
> - 对于需要严密防范幻觉的环节（比如跨境支付合规审查或复杂的供应链调度），这类能进行“内心自我修正”的底层机制将大放异彩
>

> [!NOTE]
> 1. **“永远在线” (Always-On)的系统级自主代理**
  >  
>
> - OpenAI 正在开发代号为 Hermes 的“始终在线”代理平台，允许代理独立行动而非等待提示；Anthropic 也在开发带有 UI 扩展的始终在线代理 Conway；同时，Google 推出了增强自主研究能力的 Deep Research Max

> - AI 已经突破了“一问一答”的对话框限制，转变为在后台持续运行的守护进程
>     
>
>2. **多端并行的编程工作流**
  >  
>
> - Google Gemini CLI 添加子智能体处理并行编程任务；Lovable 推出跨端 AI 编程应用，允许通过语音或文字随时切换设备进行编程
>     
> - 这不仅极大地缩短了产品从概念验证（POC）到功能性 Demo 落地的周期，也让多端碎片化时间内的代码重构成为可能
>     
>
>3. **企业级 SaaS 的“无头化” (Headless)**
  >  
>
> - Salesforce 发布 Headless 360 计划，让 AI 代理通过 API 或 MCP 工具访问平台全量功能；Claude 推出了连接器，打通了 Adobe、Autodesk 等主流创意软件
>     
> - 未来的软件将拥有两套 UI：一套给人类看，一套给 AI 看
>     
> - 在必须采用 API-First 和“无头”架构的场景中，是为了让 Agent能够直接通过系统接口进行混合作业
>     
>
>4. **下一代人机协作的交互新范式**
  >  
>
> - Stitch 将 DESIGN.md 格式开源，使其能跨平台理解设计逻辑并生成匹配的 UI；传闻 OpenAI 探讨开发智能手机，拟用 AI Agent 替代以应用为中心的界面
>     
> - 下一代人机交互（HCI）底层逻辑——需求端（OpenAI 手机）：提出“UI 按需动态生成”的命题；供给端（DESIGN.md）：提供“动态生成不崩盘”的基础设施
>     
> - OpenAI 探讨用 AI Agent 替代 App，意味着未来的交互是“意图导向”的（LUI/CUI）
>     
> - 如果 Agent 要频繁地为用户“按需生成”界面，面临的最大工程痛点是**视觉和代码的“幻觉”（样式漂移），**这就是 DESIGN.md 这种规范极其重要的原因——它是专门写给大模型看的“视觉宪法”
>     
> - 未来是 Agent 替人类跨越软件边界的时代，我们正在走向“UI 即代码，代码即意图”
>

## 4 新商业

> [!NOTE]
> 1. **Cursor：不算账的黑马遇上超级买家垄断**
 >   
>
> - AI 编程明星公司 Cursor 虽然年化销售额飙升至 27 亿美元，但上一财年却亏损了近 9 亿美元；为了维系算力，Cursor 选择了与 SpaceX 深度绑定，甚至授予了后者以 600 亿美元收购或 100 亿美元合作的极高筹码
>     
> - 极高的用户增长背后是极其恐怖的推理成本，垂直领域的“黑马”一旦长成，如果找不到能够兜底的超级算力金主（如 SpaceX 的超级计算机），很容易被算力账单拖垮
>     
>
>2. **Google：算力基础设施的底层“暗战”**
  >  
>
> - Google 正在与 Marvell 洽谈定制 AI 推理芯片，以减少对 Broadcom 的依赖 ；同时，Google 开始直接向“精选”客户（如 Anthropic 和 Meta）出售定制的 TPU 芯片，直接向 Nvidia 发起攻势。而另一边，软银则计划在美国创建一家名为 Roze 的公司，寻求 1000 亿美元估值，专门用于建设数据中心
>     
> - 硬件巨头开始切入模型，模型巨头开始自研芯片；在底层基建尘埃落定之前，保持应用层架构的高度解耦是极其必要的战略储备
>     
>
>3. **OpenAI：疯狂的估值叙事也需要商业闭环**
  >  
>
> - 曾被视为技术灯塔的 OpenAI 在冲刺 IPO 阶段未能达成收入和用户目标，高层甚至开始担忧无法支付未来的计算合同费用；为了增加营收，OpenAI 甚至开始在 ChatGPT 内部启用按点击付费（CPC）和 CPM 广告
>     
> - 连 OpenAI 都开始靠卖广告赚钱，说明单纯的“AI 订阅制”和“API 调用费”已经难以覆盖庞大的算力成本
>     
> - 对于致力于推动“代理式商业（Agentic Commerce）”的产品架构来说，这反而是个巨大的利好——因为这意味着 AI 产品的终极形态必须离钱更近，必须直接嵌入到真实的订单转化和支付网络中
>     
>
>4. **Cohere&Manus：“主权 AI”崛起&出海合规壁垒**
  >  
>
> - 加拿大的 Cohere 与德国的 Aleph Alpha 达成 200 亿美元估值的合并，明确致力于开发得到两国政府支持的“主权 AI”；与此同时，中国监管机构极其罕见地出手，直接叫停了 Meta 对 AI Agent 创业公司 Manus 20 亿美元的收购案，并限制科技公司接受美国资本
>     
> - AI 已经从“科技赛道”变成了“国家战略资产”。“主权 AI（Sovereign AI）”概念的爆发意味着，未来的全球化产品架构必须具备先决条件：数据出境合规、本地化节点部署以及接入多国本地合规模型（如欧洲用 Cohere、中国用国产模型）
>
