## When you see that incredibly sassy intro ("More integrations than your therapist's intake form"), congrats! It has successfully descended into the cloud!

"🦞 OpenClaw 2026.3.13 (61d171a) — More integrations than your therapist's intake form.
08:36:56 Missing config. Run `openclaw setup` or set gateway.mode=local (or pass --allow-unconfigured)."

The installation stopped due to missing configs. The reason:
#Because you are using a brand-new cloud computer, it doesn't have any of those initialized "brain config files." For security reasons, it sassily refuses to open the gateway doors.

Step 5: Secure Pairing Required — Success After "Almost Giving Up”

Simply put: Gemini initially kept having me modify JSON files to bypass the token verification, but it was useless because OpenClaw has strict underlying validations.
Later, I saw from the error logs that because I was forwarding ports from a VM, the "origin" address wasn't recognized as "local." OpenClaw flagged me as a potential hacker and locked the door. 

Per Gemini:
"Based on your article link and the deep logic of the Pairing Required (1008) error in the official docs, we finally found the 'official solution.' In a cloud environment like GitHub Codespaces, you’re blocked because OpenClaw uses a 'Trinity' of security: Token + TrustedProxies + Device Pairing. We had handled the first two, but got stuck on the last one: Device Pairing."
