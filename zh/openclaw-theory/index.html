关键词1：克制

My philosophy in all of this was: if I don't need it, it won't be built. And I don't need a lot of things.
我对这一切的理念是：如果我不需要它，它就不会被建造。而且我不需要很多东西。

Then just talk to pi. By default, pi gives the model four tools: read, write, edit, and bash. The model uses these to fulfill your requests. Add capabilities via skills, prompt templates, extensions, or pi packages.
然后直接和 Pi 聊聊。默认情况下，Pi 为模型提供了四个工具： 读 、 写 、 编辑和终端命令 。模型利用这些来满足你的请求。通过技能 、 提示模板 、 扩展或 Pi 包添加功能。

As it turns out, these four tools are all you need for an effective coding agent. Models know how to use bash and have been trained on the read, write, and edit tools with similar input schemas.
事实证明，这四种工具就是你打造高效编码代理所需的全部。模型会用 bash，并且已经在读取、写入和编辑工具上接受过类似输入模式的训练。

pi's system prompt and tool definitions together come in below 1000 tokens.
Pi 的系统提示和工具定义加起来不到 1000 个 token。

关键词3：体验

Many unified LLM APIs completely ignore providing a way to abort requests.
pi-ai was designed from the beginning to support aborts throughout the entire pipeline, including tool calls.
许多统一的 LLM API 完全忽视了中止请求的提供。
Pi-AI 从一开始就设计为支持整个流程中的中止，包括工具调用。

💡 流程要点：
- 中止时：Abort → Agent 停止 → 保存 partial content → UI 提示
- 恢复时：UI 触发“继续生成” → 注入 partial content → Agent 续写 → LLM 输出
- 用户最终看到的内容 = 中止前 + 续写后完整文本
- 每层职责清晰：UI 管交互、应用层管理上下文、Agent 控制循环、LLM 执行文本生成

5 两大挑战&破局思路

安全性担忧：对标Manus

产品形态交互形态安全威胁应对策略
ChatBot形态
2022-2023		文本对话框

（没有网络搜索，也还没有Function Call）		模型有了“大脑”：
直接提示词注入 (Direct Prompt Injection)
越狱 (Jailbreak)
• 主要攻击对话框
• 输出有害言论、写恶意代码文本
• 但不具备物理破坏力。		模型：微调和对齐（RLHF），“外挂过滤器（Ad-hoc Filtering）”
端口：输入和输出做安全审计和规则拦截
Copilot形态
2024-2025		RAG检索增强生成

（阅读 PDF、总结网页、查阅数据库等）		模型长出了“眼睛”：
间接/零点击注入 (Indirect & Zero-Click Injection)
• 恶意指令被嵌入到外部内容中
• 攻击者将有害提示词注入到 AI 系统经常访问的数据库或知识库中
• 因为合法内容和恶意指令混在了一起，传统过滤器失效
• AI在读数据时，读到了隐藏指令，瞬间被策反。		“数据源清洗 (Input Sanitization)”
“数据防泄漏 (DLP)”
• 限制 AI 访问敏感数据库（最小权限原则），
• 或者在 AI 返回结果前进行人工脱敏。
Agent形态
2025-至今（2026）

→这是OpenClaw今天面临的考研。		跨应用调度和本地执行代码的能力

（读取本地文件，操作终端CLI，删写邮件，修改代码等）		模型长出了“手和脚”：
• 语义越权
• RCE（远程代码执行）
• 提示词恶意软件 (Promptware)
• 安全威胁从“文本污染”正式升级为“系统级控制权夺取”。		“让 LLM 自己做安全审查”→套娃防御无效。
安防部署全面转向“建筑学级别的硬隔离”。
• 沙盒化 (Sandboxing)： 将 Agent 锁死在云端容器或本地受限 Docker 中。
• 插件供应链审查： 实时监控 Agent 工具库中的有毒技能（ToxicSkills）。
• 人类兜底 (HITL)： 强制切断 Agent 的静默写权限，任何系统调用必须让人类点击授权。
